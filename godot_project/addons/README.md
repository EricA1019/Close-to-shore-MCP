
# Addons Folder

This folder contains all downloaded Godot plugins and custom addons for the project.

## Purpose
Centralize plugin management and ensure each addon is in its own subfolder.

## Structure & Best Practices
- Place each plugin in a dedicated subfolder (e.g., `gut/`, `phantom_camera/`).
- Include a `README.md` in each plugin folder with installation and usage instructions.
- Reference `MCP/PLUGINS.md` for recommended plugins and installation steps.
- Update this README if the folder structure changes.
