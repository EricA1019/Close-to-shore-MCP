
# Scenes Folder

This folder contains all Godot scene files (`.tscn`, `.scn`) for the project.

## Purpose
Organize all game scenes in one place for clarity and maintainability.

## Structure & Best Practices
- Name scenes after their main function or entity (e.g., `MainMenu.tscn`, `Player.tscn`).
- Keep related assets and scripts in the same folder or subfolder.
- Document complex scenes with comments or a dedicated markdown file if needed.
- Update this README if the folder structure changes.
