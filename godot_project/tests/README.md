
# Tests Folder

This folder contains all automated and manual test scripts for the Godot project, including GUT tests.

## Purpose
Organize and centralize all project tests for reliability and maintainability.

## Structure & Best Practices
- Group tests by feature or module in subfolders (e.g., `unit/`, `integration/`, `smoke/`).
- Use clear, descriptive names for test files.
- Document test setup and usage in this README or a dedicated file.
- Update this README if the folder structure changes.
