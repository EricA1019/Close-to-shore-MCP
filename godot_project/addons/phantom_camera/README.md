# Phantom Camera Plugin

This folder contains the Phantom Camera plugin for Godot. For installation and usage instructions, see the main documentation in `MCP/GODOT_TOOLS/phantom_camera_plugin.md`.

## Quick Start
1. Enable the plugin in Project Settings > Plugins.
2. Use WASD and mouse to control the camera.
3. Adjust plugin settings as needed.
