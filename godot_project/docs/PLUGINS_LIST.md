# Recommended Godot Plugins

This template supports and recommends the following plugins:

- **GUT**: Unit testing for Godot (https://github.com/bitwes/Gut)
- **Dialogic**: Dialogue system (https://github.com/coppolaemilio/dialogic)
- **Inventory System**: Inventory management (https://github.com/godot-extended-libraries/godot-inventory-system)
- **Maaack Game Template Addon**: Automation and workflow helpers
- **Any other plugin** that improves your workflow

## Purpose
Centralize plugin recommendations, installation, and update instructions for maintainability.

## Structure & Best Practices
- Place each plugin in its own subfolder in `addons/`.
- Include a `README.md` in each plugin folder.
- Track plugin versions and update logs.
- Document any customizations or modifications.

## Update & Log
- Use the "Update Plugins" and "Update All Docs" tasks to keep plugins and docs current.
- Log major plugin changes in this file or a dedicated changelog.

## Last Updated

## Installation
- Download each plugin into `godot_project/addons/`
- Enable in Godot editor (Project > Project Settings > Plugins)
- Document usage and update instructions in this file

## Update Instructions
- Use the plugin manager tool to check for updates
- Review plugin docs for new features and changes

## Notes
- All plugins should be MIT-licensed or compatible
- Document any modifications or customizations
