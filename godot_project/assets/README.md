
# Assets Folder

This folder contains all images, audio, and other assets for the Godot project.

## Purpose
Centralize game assets for easy access and management.

## Structure & Best Practices
- Organize assets by type (e.g., `images/`, `audio/`, `fonts/`).
- Use clear, descriptive names for files and folders.
- Include license and source information for third-party assets.
- Update this README if the folder structure changes.
