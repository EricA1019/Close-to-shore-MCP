# Godot-4-ASCII-Grid Plugin Documentation

This plugin provides a flexible ASCII grid renderer for Godot 4, suitable for roguelike and retro-style games. It supports monospaced Unicode fonts, color customization, and grid-based rendering.

## Features
- Monospaced grid rendering (ASCII/Unicode)
- Customizable font and colors
- Supports CP437 and other Unicode fonts
- API for updating grid cells, colors, and glyphs
- Designed for top-down, roguelike, and retro games

## Installation
1. Clone the repository into your project's `addons` directory:
   ```bash
   git clone https://github.com/SelinaDev/Godot-4-ASCII-Grid.git addons/Godot-4-ASCII-Grid
   ```
2. Enable the plugin in Project Settings > Plugins.

## Usage
- Add an `AsciiGrid` node to your scene.
- Configure grid size, font, and colors in the Inspector.
- Use the provided API to update grid cells and display game state.
