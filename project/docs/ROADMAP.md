
# Broken Divinity: New Babylon — Roadmap

This roadmap is a flexible checklist for development. Each hop is a focused, test-driven milestone.

## Hops Checklist

- [ ] **Hop 1: Five-Panel UI Setup**
  - Create main scene with five panels: Main, Output, Action, Debug, Status
  - Add placeholder text to each panel for layout verification
  - Add basic tests for panel presence and wiring

- [ ] **Hop 2: Opening Scene Integration**
  - Wire four-panel UI to the opening apartment scene
  - Ensure scene flow matches the prototype outline
  - Add tests for scene transitions and UI state

- [ ] **Hop 3: ASCII Grid Integration**
  - Integrate Godot-4-ASCII-Grid plugin for main panel rendering
  - Display simple ASCII room in main panel
  - Add tests for grid rendering and font/color setup

- [ ] **Hop 4: Character Creation System**
  - Implement mirror-triggered character creation scene
  - Add background and personal touch selection
  - Add tests for character creation flow

- [ ] **Hop 5: Inventory and Gear System**
  - Implement inventory UI and equip logic
  - Add tests for item equip, stat modification, and ability assignment

- [ ] **Hop 6: NPC and Combat System**
  - Add Dona Margarita and imps to alley scene
  - Implement turn-based combat, damage types, and buffs
  - Add tests for combat flow and permadeath

- [ ] **Hop 7: Faction and Badge Mechanics**
  - Implement Morning Star badge and faction interactions
  - Add tests for badge effects and NPC responses

- [ ] **Hop 8: Settlement Management**
  - Implement resource production and militia recruitment
  - Add suffix system for troops
  - Add tests for resource flow and recruitment

- [ ] **Hop 9: Ruins and Dungeon System**
  - Implement ruins exploration, random events, and dungeon crawl
  - Add tests for procedural generation and loot assignment

- [ ] **Hop 10: Save/Load System**
  - Integrate JSON save system (3 slots)
  - Add tests for save/load reliability and metadata

- [ ] **Hop 11: Polish and Demo End**
  - Add splash screen, credits, and final polish
  - Refactor, document, and update project index

---
Refer to this checklist for planning, tracking, and reviewing each development hop.

## Success Metrics
- [ ] Application boots without errors
- [ ] All tests pass consistently
- [ ] Core user workflows complete successfully
- [ ] Performance meets basic requirements
- [ ] Documentation is complete and current

*Keep this living document updated as priorities shift and new discoveries emerge.*
