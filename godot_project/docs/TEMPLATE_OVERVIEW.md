# Godot MCP Template Overview

## Summary
This project is a reusable, modular template for Godot games, integrating the Minimal Change Process (MCP) methodology and best practices learned from experience. It combines:
- Core MCP workflow and documentation
- Maaack Game Template automation and structure
- Offline docs for Godot Engine and GUT
- Recommended plugins and tools
- Ready-to-use folders for scripts, scenes, assets, tests, and addons

## Purpose
Provide a standardized starting point for Godot projects, ensuring maintainability, scalability, and rapid onboarding.

## Structure & Best Practices
- Follow folder conventions (`src/`, `scenes/`, `assets/`, `addons/`, `docs/`, `tests/`, `data/`).
- Use clear, descriptive names for files and folders.
- Document all major systems and workflows.
- Keep changelogs and update logs for transparency.
- Regularly update plugins and docs using automation tasks.

## Update & Log
- Use the "Update All Docs" task to keep documentation in sync.
- Log major changes and lessons learned in `LESSONS_LEARNED.md`.

## General Goals
- Provide a plug-and-play Godot project template for rapid prototyping and production
- Integrate hard-learned lessons (entity system, turn order, battle managers, etc.)
- Make workflow smooth and consistent across all projects
- Ensure all code and assets are MIT-licensed and properly attributed
- Enable easy updates and plugin management

## Possible Plugins
- GUT (Godot Unit Test)
- Dialogic (dialogue system)
- Inventory System
- Maaack Game Template Addon
- Any other Godot plugin useful for your workflow

## Features
- Entity system, turn order, battle manager stubs
- Automated scene/script indexing
- Test runner integration
- Plugin manager for easy updates
- Local documentation for engine and tools
- Example scenes, assets, and UI themes
