# Phantom Camera Plugin

## Overview
The Phantom Camera plugin for Godot provides advanced camera controls, including free-fly, collision avoidance, and debug features for level design and testing.

## Features
- Free-fly camera movement
- Collision detection
- Debug overlays
- Customizable controls

## Installation
1. Download the Phantom Camera plugin from its official repository:
   - [GitHub: Phantom Camera](https://github.com/ramokz/phantom-camera)
2. Place the plugin folder in your project's `addons/phantom_camera/` directory.
3. Enable the plugin in Project Settings > Plugins.

## Usage
- Activate the Phantom Camera from the editor or via script.
- Use WASD and mouse to navigate.
- Adjust settings in the plugin panel for speed, collision, and overlays.
