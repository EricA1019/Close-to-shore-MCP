# Phantom Camera Plugin Documentation (Summary)

## Overview
Phantom Camera is a Godot 4 plugin inspired by Unity's Cinemachine, providing advanced behaviors for Camera2D and Camera3D nodes. It supports smooth following, dynamic framing, multi-target tracking, and animated transitions between camera positions.

## Features
- Priority-based camera switching
- Multiple follow modes: Glued, Simple, Group, Path, Framed, Third Person
- Zoom (2D), Look At (3D), Group Look At
- Tweening for smooth transitions
- Viewfinder preview
- Example scenes for 2D and 3D

## Installation
- Asset Library: Search "Phantom Camera" in Godot's AssetLib, install, and enable in Project Settings > Plugins.
- GitHub Releases: Download release, extract `addons/phantom_camera` to project root, enable plugin.
- GitHub Main: Download main branch, extract, move to project root, enable plugin.

## Usage
- Add PhantomCamera nodes to your scene.
- Configure follow, look-at, and framing modes in the inspector.
- Use example scenes for reference.
